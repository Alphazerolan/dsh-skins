皮肤中心发布 0.4.7，沿用 dsh-web 家族的统一版本号。本版本新增两套皮肤（终末地 · BAKER 与冰蓝气泡玻璃），重做 miku 的配色与元素，把 verdandi 的运行状态行整条接管，并修掉会话切换时的规则匹配开销、鲸鱼娘 · 水墨丹青的循环接缝与若干皮肤在真实壳层上的渲染缺陷。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-client-ui-skin-center` 与安装方式不变：npm 包仍然只内置 `blue-fantasy`，两套新皮肤都是市场内容，按需装到 `$DSH_HOME/skins/<id>/`。

### 新功能

- 新皮肤：终末地 · BAKER（Endfield Baker）——把 dsh Web GUI 改画成《明日方舟：终末地》的现场终端：会话区是 BAKER 通讯界面（青色标头竖条、信号黄选中行、切角控制台卡片、白色胶囊输入条、磨砂灰聊天底板），其余壳层用细网格、斜纹信号条与单像素浅灰描边补齐。浅色与深色共用同一套终端配色，全部颜色收在 `skin.css` 的 `:root` 里，换配色是改一个块。真机验证走无头探针读计算样式与元素矩形，而不是看图；网页构建与 Electron 桌面构建的 CSS-module 哈希不同，底板与竖条把手在一个 `:is()` 选择器里成对匹配。同时修掉一处真缺陷：输入区的磨砂曾给宿主的固定定位浮层造出包含块，任务运行时会把消息区与输入区整体抬高约 510 px，磨砂改挂到无子元素的 `::before` 上。主操作按钮满足对比度门（`#131514` 压在 `#19cffd` 上 9.9:1）
- 新皮肤：冰蓝气泡玻璃（Frutiger Aero Glass）——原创程序化壁纸（天空渐变、阳光、白云、草地，不含任何第三方图像）垫在冰蓝半透明玻璃面板之下，背景里六枚纯 CSS 径向渐变气泡持续上浮；整窗只在顶边留一道连续高光。全部 `--dsw-alias-*` 与 `--aion-*` token 重映射为冷色体系，浅色是正午晴空、深色是入夜后的冷海，正文与次要文字的对比度按真实合成底色核算，两套配色均达 WCAG AA。发布版本为 1.1.0，面板磨砂改为预烘进壁纸资源，不再逐帧回读整屏
- miku 0.5.1（声波青）：三支主色收成一支青绿（深墨青与 `#39c5bb` 承字，亮青绿只当填充，洋红只给用户自己的轮次），字体由 Bahnschrift 换成 Inter + Noto Sans SC；母题从机甲语汇换成声波——空会话首屏一排细声波柱、输入卡底缘一道聚焦时亮起的信号线、品牌行一枚 MIKU 徽标，样式表里不再有 `clip-path`，焦点环回到普通 outline。宿主写死面色的两处按宿主自己的钩子接管：浮动状态气泡（宿主把文字与 1px 边都写成同一个颜色，明暗两档一模一样，压在浅色插画上等于看不见）与 usage 插件在侧栏底部的用量卡。140 个自定义属性一个不少，明暗各 20 组关键配对全部 >= 4.5:1，自定义光标与设备适配两段逐字节保留
- verdandi 整条接管宿主运行状态行：dsh 0.2.0 把运行中状态挂成独立节点，皮肤因此可以接管整行——图标、文案与扫光都由皮肤绘制（图标是 14px 的剑的绘制，配呼吸式摆动；文案是一条平铺的渐变层，收在墨色上，不会透出重影），宿主自己的尾串（`, 用时 20 秒 ···`）逐字保留、继续跳动，只替换前导短语。宿主的活动区由皮肤自己的区域替换，且带着宿主原有的短语；钩子被拒或短语不认识时失败关闭，宿主那一行保持不动

### 修复

- 语义适配器的规则匹配按批次收敛并收窄：一次会话切换会多出 20,000–31,000 次 `Element.matches()`（zhu1090093659/dsh-web#1870），原因是每条 `childList` 记录各自向上走 24 层祖先、每层都跑全部 24 条规则，属性记录同样全量走一遍，而观察者的 `attributeFilter` 又包含适配器自己写入的属性，于是每次盖章都回声成一条新记录再走一遍全文。现在先收集后求值（同一次投递里每个祖先最多被检查一次）、按选择器形态把表拆开（只有含 `:has(`、`:empty`、兄弟位置伪类与 `:nth-` 的规则会被祖先行走翻转，今天正好两条）、属性记录只挑选择器里点到该属性的规则、被另一个新增根包含的新增根直接跳过。夹具上的切换开销由 242,880 次 `matches()` 降到 15,600 次，盖章结果不变（同样 242 处），公共 API 与诊断结构未动
- 鲸鱼娘 · 水墨丹青的背景循环接缝：发行档起于宣纸、止于墨，于是每 25.333 秒从一端硬切到另一端（接缝 171.06，而 p95 逐帧步长只有 8.70，是最大普通步长的二十倍）。编码本来就要重做一遍（HEVC 在 Electron 壳里放不出来），接缝在同一趟里补上：最后 1.2 秒交叉溶解到第 0 帧的克隆，接缝降到 0.01，帧数、帧率、时长与分辨率一律不变，素材由 23.08 MiB 降到 20.54 MiB
- stellar-diva 亮色提示气泡改成深底：宿主提示文字的颜色是写死的 `--dsw-static-neutral-bluish-00`（`#fff`），皮肤令牌改不动它，而亮色主题把 `--dsw-alias-tooltip-bg` 设成了纯白，白底白字完全不可见（#72）。改用皮肤自身的蓝宝石深色 `#33456E`（与暗色主题同一种深底策略），白字对比度 9.47:1，`tooltip-fg` 同步为 `#E9EEFF`，并补了锁定两套主题都满足 4.5:1 的回归测试
- frutiger-aero 1.1.0 把面板磨砂从实时计算里拿掉：气泡在面板背后持续上浮，`backdrop-filter` 因此每帧回读并重算整屏模糊，集成显卡（Intel Iris Xe，1920x1200 最大化）上 3D 引擎占用 82.33%。改为把「2px 柔化 + 冷色 1.06」预烘进壁纸资源，四处 `backdrop-filter` 改成 `var(--aero-frost, none)`，占用降到 22.79%，整窗观感差异 2~3 级。同一轮还修掉壁纸太阳周围因「模糊 + 8bit 量化」留下的同心环（同值平台像素 10,062 → 884），以及浅色侧栏工作区列表被云朵图案干扰的对比度问题（文字背后底色标准差 21.7 → 11.7，最差行 6.35:1 → 9.48:1）
- blueprint 移除 HUD 顶栏并让开 Windows 原生标题栏：顶栏是钩子注入的 `position: fixed; top: 0` 横条，在打包版 Windows 应用里整条 30 px 落在原生标题栏带内，读数被压住，占用的高度也没归还给内容。现在画框顶到 y=0、高度改为 100vh 减底栏，底栏的实时读数与标尺保留，角定位标记与侧栏开关簇改为跟随宿主只在 Windows 上写入的 `--dsh-bp-caption-top` 让位（其他主机取 0px 回退，行为不变）。商店预览随之重出——旧预览还是顶栏在时的实拍，与现状对不上
- miku 删掉 `[class*="crumb"]` 通配：这条通配会把宿主所有 `*crumb*` 类名一并隐藏，而宿主里这些类名清一色是导航控件（插件详情页的返回插件列表入口、会话头的子代理返回路径、选目录弹窗的路径栏、@ 触发菜单的来源行），激活 miku 后插件详情页因此失去返回入口
- verdandi 在真实壳层上的渲染缺陷：注册面板行不再自带金环、字形槽与额外间距，六个侧栏行统一为 36px 高、标签对齐同一缩进；轨迹面板同时锚定 `aria-label` 的中英两种写法（宿主会本地化），历史控件不再是吃满上下边的 999px 胶囊；两个此前从未匹配到的状态补上——发送按钮的 `aria-label` 会在四个值之间轮换而皮肤只列了两个，于是一开工就丢掉红与剑的处理，而 macOS 的 `data-platform="darwin"` 标记会用宿主自己的填充重画新会话按钮。美术资源的 URL 变量也从 `body.style.setProperty` 移进 `skin.css` 的 `:root`，使其能穿过皮肤中心的双重激活清理，并删掉一批宿主类名已不存在的选择器
- verdandi 分体标头的两个胶囊、被压住的头菜单与 `composer` 印章：三点缺陷里两处是同一类错误——皮肤抬起的图层压在宿主自己的界面之上。分体控件 `div > button + button` 被一律胶囊化，接缝处露出缺口与两道内环，现在整组是一个胶囊、两半在里面保持方角无边框，标签页列表被排除在外；标题行被套进 `display: contents` 的座位后 `z-index: 3` 只算到 0-3-0，被 0-2-0 的标签行压过头菜单并吃掉第一次点击，抬升改为 0-3-0 以上并同时按结构匹配；印章不再盖住模型选择器，皮肤自带的抬升收进个位数，印章排在 `composer` 自身内容之下
- verdandi 不再把画框的装饰层塞进窗口的拖拽区：宿主把标头与标题行标成 `-webkit-app-region: drag`、把控件标成 `no-drag`，而这个属性会继承，皮肤挂进标头的每层装饰都继承了 `drag`，真实鼠标按下变成拖窗口而不是点按钮。装饰层改为 `no-drag` 后，宿主按「每个 `drag` 元素的矩形减掉自己的 `no-drag` 后代」计算的区域又整条被挖掉，于是补一层只覆盖标头中间空档的 `header-drag-strip`（左 40%、宽 20%、`pointer-events: none`，与任何控件都不重叠），并且只在标头的计算区域确实是 `drag` 时挂载——Windows 用不上这个属性，不该凭空造出一块宿主没预留的区域
- verdandi 在插件页把角色立绘退到内容之后：舞台是 `position: absolute; z-index: 0`，而插件页是普通流内容，定位盒排在流内盒之后，于是立绘盖住卡片。主座位里出现插件面板或详情面时舞台降到 `z-index: -1`（页面自有背景就看不见，没有背景就从缝隙里透出来），会话页保持原样
- 终末地 · BAKER 同步到 0.9.1：把桌面构建的 CSS-module 哈希变体与网页构建成对匹配（原来只认网页构建的一套），全屏右侧面板完全盖住底下的工作区，提问卡的表头保持素面而不带会话插画

### 其他改动

- 语义属性契约删掉 dsh-model-capabilities：家族仓移除了这个插件，官方 0.2.1 的 Models 界面覆盖了它的 provider 卡片扩展面板，于是不再有节点写 `data-dsh-plugin="model-capabilities"`。`contracts/semantic-attrs-v1.md` 里八行 `data-dsh-part` 与一行 `data-dsh-plugin` 删除（分组标题按实际表格重新点过：part 78 行、plugin 14 行），claude 的共享插件卡规则与选择器策略注释同步去掉这个选择器
- SDK 队列推进到 0.2.1-rc.2：声明的宿主下限、`@deepseek-ai/dsh` 的 peer 约束、九个精确固定的 SDK 开发依赖与锁文件一起走，vendor 钉子对齐队列的稳定同伴（cordis ^4.0.5、schemastery ^3.18.5、cosmokit 解析到 1.8.6）。rc.2 的接口不需要改动本仓的契约或代码，构建产物里只有版本号一处变化
- 终末地 · BAKER 的样式表统一为 LF：这个 blob 曾以 CRLF 进主干，而市场产物由父仓按钉住的提交重建并与已提交的 dist 比对，一次全新检出是 LF，于是零可见字节差异也会让比对失败
- Agent Notes 记录 2026-10-12 至 2026-10-16 的四轮皮肤收件，以及皮肤开发者文档、素材来源与授权范围的补充说明；新增两套皮肤的明暗证据图，miku 0.5.1 的证据截图入库，frutiger-aero 的证据图与预览图重拍（去掉了第三方桌宠）

The skin center publishes 0.4.7 on the family's shared version line. This release adds two skins (Endfield Baker and Frutiger Aero Glass), reworks miku's palette and elements, takes the verdandi running line over end to end, and fixes the rule-matching cost of a session switch, the Whale Girl · Ink Wash loop seam, and a set of skin rendering defects found on the real shell.

> **Important change**: there is nothing to migrate by hand in this release. No persisted identifier, wire field or profile format was renamed. The package name `@linxin666/dsh-client-ui-skin-center` and its install path are unchanged: the npm package still ships only `blue-fantasy`, and both new skins are market content installed on demand into `$DSH_HOME/skins/<id>/`.

### New Features

- New skin: Endfield Baker - the dsh web GUI redrawn as an Arknights: Endfield field terminal. The session area becomes the BAKER comms screen (cyan header rail, signal-yellow selected row, cut-corner console cards, white capsule composer, frosted grey chat base plate) and the rest of the shell is filled in with fine grids, striped signal bars and single-pixel grey rules. Light and dark share one terminal palette held entirely in `skin.css`'s `:root`, so a scheme change is a one-block edit. Verification ran a headless probe reading computed styles and element rects rather than eyeballing screenshots, and because the web and Electron desktop builds hash their CSS modules differently the base plate and the rail handle pair both spellings in one `:is()` selector. One real defect was fixed on the way: the composer frost used to create a containing block for the host's fixed-position floating bubble, lifting the message area and the composer by about 510 px while a turn ran; the frost now lives on a child-free `::before`. The primary action keeps a 9.9:1 contrast gate (`#131514` on `#19cffd`)
- New skin: Frutiger Aero Glass - an original procedurally generated wallpaper (sky gradient, sun, clouds, grass; no third-party image anywhere) under ice-blue translucent panels, with six pure-CSS radial-gradient bubbles rising behind them and a single continuous highlight along the top edge instead of a ring per panel. Every `--dsw-alias-*` and `--aion-*` token is remapped onto a cold palette: noon sky in light, a cold night sea in dark, with body and secondary text contrast computed against the real composited base, both schemes at WCAG AA. It ships as 1.1.0, where the panel frost is pre-baked into the wallpaper asset instead of being recomputed per frame
- miku 0.5.1 (sonic cyan): three primary colours collapse into one cyan-green (deep ink-cyan and `#39c5bb` carry text, bright cyan-green is fill only, magenta belongs to the user's own turns), and the type moves from Bahnschrift to Inter + Noto Sans SC. The motif changes from mecha vocabulary to a sonic wave: a row of thin wave bars on the empty first screen, a 2px signal line under the composer that lights on focus, a MIKU badge on the brand row, no `clip-path` left in the stylesheet so focus rings return to a plain outline. Two surfaces the host paints from its own constants are taken over through the host's own hooks: the floating status bubble (the host writes text and its 1px border in the same colour, identical in both themes, so it disappeared on light artwork) and the usage card the usage plugin pins at the bottom of the sidebar. All 140 custom properties survive, 20 key pairs per scheme all measure >= 4.5:1, and the custom cursors and device adaptation are preserved byte for byte
- verdandi takes the host's running line over end to end: dsh 0.2.0 mounts the running status as a node of its own, so the skin can own the whole line - icon, copy and sweep (the icon is the drawn 14px sword with a breathing swing; the copy is one tiled gradient layer ending in ink, so no band can ghost). The host's own tail (`, 用时 20 秒 ···`) stays verbatim and keeps ticking while only the leading phrase is swapped, and the host's live region is replaced by the skin's carrying the host's own phrase. It fails closed: a refused hook or an unknown phrase leaves the host's line alone

### Bug Fixes

- The semantic adapter batches and narrows its rule matching: a single session switch produced 20,000-31,000 extra `Element.matches()` calls (zhu1090093659/dsh-web#1870). Every `childList` record re-anchored on its own, walking up 24 ancestors and evaluating all 24 rules at each hop; attribute records paid the same full walk, and the observer's `attributeFilter` includes the attributes the adapter stamps itself, so every stamp echoed back as a new record and triggered another walk. The callback now collects first and evaluates second (each ancestor is rule-checked at most once per delivery), splits the table by selector shape (only rules containing `:has(`, `:empty`, the sibling-position pseudo-classes or `:nth-` can be flipped by an ancestor walk - today exactly two do), lets an attribute record select only the rules whose selector names that attribute, and skips an added root contained in another added root of the same delivery. The fixture's switch cost drops from 242,880 `matches()` calls to 15,600, with the same 242 stamps and an untouched public API and diagnostics shape
- Whale Girl · Ink Wash background loop seam: the shipped background began on rice paper and ended on ink, so every 25.333 s the loop point cut from one to the other (seam 171.06 against a p95 frame-to-frame step of 8.70, twenty times the largest ordinary step). The encoder had to change anyway (HEVC does not play in the Electron shell), so the seam is closed in the same pass: the last 1.2 s cross-dissolves into a clone of frame 0, measuring 0.01, with frame count, frame rate, duration and resolution untouched and the asset down from 23.08 MiB to 20.54 MiB
- stellar-diva's light tooltip gets a dark ground: the host fixes tooltip text to `--dsw-static-neutral-bluish-00` (`#fff`) and no skin token can move it, while the light theme had set `--dsw-alias-tooltip-bg` to pure white, leaving white on white (#72). It is now the skin's own sapphire dark `#33456E` (the same dark-ground strategy as the dark theme), 9.47:1 against the white text, with `tooltip-fg` at `#E9EEFF` and a regression test pinning both theme blocks above 4.5:1
- frutiger-aero 1.1.0 takes the panel frost out of live computation: bubbles rising behind the panels made `backdrop-filter` read back and recompute a full-screen blur every frame, costing 82.33% of the 3D engine on integrated graphics (Intel Iris Xe, 1920x1200 maximised). The "2px softening + cold 1.06" is pre-baked into the wallpaper asset and the four `backdrop-filter` declarations become `var(--aero-frost, none)`, bringing it to 22.79% with a 2-3 level whole-window difference. The same round removes the concentric rings the sun halo picked up from blur plus 8-bit quantisation (flat-equal pixels 10,062 -> 884) and fixes the light sidebar workspace list sitting on the cloud pattern (local background standard deviation 21.7 -> 11.7, worst row 6.35:1 -> 9.48:1)
- blueprint drops its HUD title bar and clears the Windows native title bar: the bar was a hook-injected `position: fixed; top: 0` strip that, in the packaged Windows app, landed entirely inside the 30 px native title-bar band where the app/edit menus and window buttons live, pressing its readouts flat and never returning the height it took. The frame now reaches y=0 with its height as 100vh minus the bottom bar, the bottom bar keeps every live readout and the ruler, and the corner marks and sidebar-toggle cluster follow `--dsh-bp-caption-top`, which the host writes only on Windows (absent elsewhere, so other hosts fall back to 0px and are unchanged). The store preview is reissued with it, since the old preview still showed the deleted bar
- miku drops its `[class*="crumb"]` wildcard: it hid every host class containing `crumb`, and in the host those are all navigation controls (the plugin detail page's back-to-list entry, the session header's subagent return path, the directory picker's path bar, the @ trigger menu's source row), so activating miku removed the way back out of a plugin detail page
- verdandi rendering defects on the real shell: registered panel rows no longer carry their own gold ring, glyph slot and extra margin, so all six sidebar rows compute to 36px with one label indent; the trace panel anchors both the English and Chinese spellings of its `aria-label` (the host localises it) and the history control is no longer a 999px pill eating its own top and bottom edges; two states that were never matched are covered - the send button cycles its `aria-label` through four values while the skin listed two, so the crimson-and-sword treatment was dropped the moment a turn started, and the macOS `data-platform="darwin"` marker repaints the new-session button with the host's own fill. The art URL variables also move from `body.style.setProperty` into `skin.css`'s `:root` so they survive the skin center's double-activation cleanup, and selectors whose host class no longer exists are gone
- verdandi's split header controls, buried header menu and composer seal: two of the three were the same mistake - a layer the skin raised ending up on top of the host's own UI. The shell's "open with <app>" control is `div > button + button` and a blanket pill pilled each half, so the seam showed a notch and two inset rings; the pair's box is the pill now, the halves stay square inside it and the tab list is excluded. The title row, nested inside the `display: contents` seat, computed its `z-index: 3` to 0-3-0 and lost to the 0-2-0 tab row, which painted over the more-actions menu and ate the first click; the lift is now 0-3-0 or higher and matched structurally as well as by class. The composer seal no longer covers the model picker: the skin's own lifts stay in single digits and the seal sits below the composer's content
